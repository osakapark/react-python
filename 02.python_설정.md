##2. sqllite (async)
```
1. 필요 패키지 설치
# SQLAlchemy 2.0 (async 지원) + Alembic
pip install "sqlalchemy[asyncio]"
pip install alembic

# SQLite async 드라이버
pip install aiosqlite

2. Alembic 초기화 (async 템플릿)
alembic init -t async alembic
alembic init -t async migrations

3.확인
alembic.ini의 sqlalchemy.url을 sqlite+aiosqlite:///./app.db 형태로 설정
env.py의 target_metadata를 모델의 Base.metadata로 연결

4.칼럼 변경
alembic revision --autogenerate
alembic upgrade head
```
